# 기존 안내 화면에서 사진 제보 우회 테스트

로컬 개발 모드에서 지도 → 경로 검색 → 안전 보행 안내 화면을 열면 **경로 위 사진 제보 테스트** 버튼이 표시됩니다. 별도 장소 검색이나 테스트 화면은 필요하지 않습니다.

1. 이용자 유형을 휠체어나 고령 보행자로 설정하고 100m 이상인 보행 경로를 검색합니다.
2. 안내 화면에서 **경로 위 사진 제보 테스트**를 누릅니다. 기본 공사 도식 이미지와 모의 위험 제보가 남은 경로 중간에 추가됩니다.
3. 직접 고른 사진을 사용하려면 **내 사진을 선택해서 테스트하기**를 누릅니다.
4. 위험 지점을 피하는 경로 계산이 완료되면 지도, 거리, 회전 안내와 음성이 새 경로 기준으로 바뀝니다. 계산 중에는 이전 경로를 유지합니다.
5. 위험 마커를 누르면 첨부 이미지를 확인할 수 있습니다. 안내 패널은 스크롤할 수 있습니다.

안내 시작 전 테스트는 지도에 표시된 출발점 기준입니다. 안내 시작 후에는 현재 GPS 위치를 사용합니다. 현재 위치가 경로에서 60m 이상 떨어져 있으면 시작 전 테스트를 이용하거나 현재 위치에서 다시 경로를 검색해 주세요. 테스트는 갤러리 사진을 업로드하거나 AI 분석하지 않고, 위험도 100% 공사 제보로 가정합니다. 실제 제보 DB에 저장하지 않으며 안내 화면을 나가면 사라집니다. 기본 이미지는 실제 현장 사진이 아닌 테스트 도식입니다.

실제 안내 중에는 앱이 전면에 있는 동안 현재 위치 1km 주변의 제보를 5초마다 확인합니다. 안내 화면을 연 뒤 등록된 활성·검증 제보 중 위험도 0.6 이상(휠체어 계단 제보는 낮은 위험도도 포함)이 앞으로 지날 경로 18m 이내에 있으면 다시 탐색합니다. 이미 지난 구간과 옆 도로는 제외합니다. 서버 푸시나 백그라운드 감시는 포함하지 않습니다.

우회 요청은 기존 목적지와 이용자 유형을 유지하고 이전에 피한 위험 지점도 함께 피합니다. 새 제보 구간을 지나는 후보나 멀리 떨어진 도로로 출발·도착점을 옮긴 후보는 제외합니다. 안전한 대안이 없거나 요청이 실패하면 경고를 표시하고 기존 경로를 유지합니다. 실제 길이 변경됐다고 표시하지 않습니다. 실제 안내 중 미해결 제보는 30초 후 다시 계산합니다.

## 로컬 실행

VS Code 터미널 1:

```powershell
cd C:\Users\Admin\OneDrive\문서\GitHub\aix_hackathon\services\api
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --reload-dir app --host 0.0.0.0 --port 8001
```

터미널 2:

```powershell
cd C:\Users\Admin\OneDrive\문서\GitHub\aix_hackathon\apps\mobile
npx expo start --offline
```

에뮬레이터를 켠 뒤 Expo 터미널에서 `a`를 누릅니다. 이 PC는 다른 프로젝트와의 충돌을 피하려고 API 포트 8001을 사용합니다. `.env`의 `EXPO_PUBLIC_API_URL`도 같은 포트를 사용해야 합니다. Expo의 `--offline` 옵션과 관계없이 지도·DB·ORS 경로 계산에는 인터넷이 필요합니다. 이미 서버가 실행 중이면 중복 실행하지 않습니다.
